# Microempresa

Aplicacion web para la gestion basica de una microempresa. Incluye modulos de
usuarios y roles, clientes, proveedores, productos, compras, ventas, reportes y
auditoria, con un panel centralizado para operar el negocio.

## Demo

URL desplegado: https://microempresa.onrender.com

Nota: si el sitio estuvo inactivo, la primera solicitud puede tardar un poco.
Esto es normal en el plan gratuito de Render, donde el servicio entra en reposo
para ahorrar recursos.

## Tecnologias

- Frontend: React
- Backend: Python (Flask)
- PDF/QR: jsPDF, pdfjs, QRCode

## Funcionalidades principales

- Autenticacion y recuperacion de contrasena por token
- Gestion de clientes, proveedores y empleados
- Gestion de productos, compras y ventas
- Reportes y registros de auditoria
